# 二轮电瓶车换电平台 — 简历素材

## 项目概述（一句话）

基于 Golang 的微服务架构二轮电瓶车换电平台，涵盖智能换电柜物联网接入、用户订单管理、企业骑手套餐计费、工单调度、电子签章、消息通知等核心业务，支持日均千级换电柜设备在线管理与调度。

---

## 技术栈

- **后端框架：** GoFrame v2、gRPC、Protobuf
- **数据库：** MySQL（InnoDB）、Redis
- **消息中间件：** RabbitMQ、MQTT
- **服务注册与发现：** Etcd
- **文件存储：** 阿里云 OSS
- **第三方服务：** 支付宝开放平台、法大大电子签章、微信小程序、短信服务
- **部署：** Docker

---

## 核心职责 / 项目经验（按模块拆分，选 4-6 条）

### 1. 换电柜 IoT 设备接入

- 基于 TCP 长连接 + MQTT 双协议实现换电柜设备的注册、心跳保活、状态同步与远程控制，设计了消息协议解析框架（登录认证、属性上报、告警上报、数据查询、控制响应等 10+ 种报文类型），支持多设备并发连接与断线重连。

### 2. BMS 电池管理系统接入

- 独立开发 BMS 服务模块，通过 TCP 服务接收电池 BMS 设备上报的实时数据（电池属性、告警信息、控制指令），并利用 RabbitMQ 实现设备数据与业务系统的异步解耦，保障高并发下的消息可靠性。

### 3. 用户体系与权限管理

- 基于 JWT + Redis 实现用户登录态管理，支持账号密码、微信、支付宝多渠道登录；结合验证码防刷与 Token 过期刷新机制，保障用户会话安全。

### 4. 企业骑手套餐与计费引擎

- 设计企业用户-骑手套餐管理体系，实现套餐购买、额度管理、过期自动计算与逾期冻结等核心逻辑；通过定时任务（Cron）逐日统计企业客户套餐使用情况，自动触发逾期天数扣减和冻结操作。

### 5. 工单系统

- 设计并实现换电柜运维工单模块，涵盖工单创建、状态流转、处理人分配与闭环追踪，支撑线下运维团队的高效调度。

### 6. 电子签章集成

- 集成法大大电子签章 SDK，实现企业用户入驻合同的在线签署流程，支持合同发起、签署状态回调、签署结果 PDF 归档等完整链路。

### 7. 通知中心

- 基于 RabbitMQ 构建统一消息通知服务，采用发布/订阅模式解耦业务系统，支持短信、站内信等多种通知渠道的扩展与路由。

### 8. 微服务架构与部署

- 采用微服务拆分架构，按业务域拆分为用户服务、换电柜服务、BMS 服务、工单服务、定时任务服务等独立部署单元，各服务通过 Etcd 实现服务注册与发现，gRPC 实现服务间 RPC 调用，基于 Docker 实现容器化部署。

## 面试可展开的要点

### TCP 长连接管理

- 如何设计连接池、如何处理粘包/半包、心跳间隔与超时判定、断线后的重连与状态恢复。

### 高并发场景

- 换电柜并发连接下的内存占用、goroutine 管理、Redis 原子操作（如定时任务中的分布式锁）。

### 消息可靠性

- RabbitMQ 的 Queue 设计、自动 ack 与消息丢失风险、BMS 数据入库的幂等性保证。

### 定时任务

- Cron 任务如何避免多实例重复执行（Redis 分布式锁）、大数据量遍历的分页策略。

### 协议设计

- 换电柜通信协议的字段设计、扩展性考虑、版本兼容。
